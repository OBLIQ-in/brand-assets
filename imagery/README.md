# Imagery & Graphic Assets

This directory contains illustrations, background patterns, social share cards, and marketing imagery for Obliq projects.

---

## 📂 Guidelines for Imagery

1. **Formats**:
   - Vector graphics / decorative accents: **SVG**
   - Photographic / complex raster imagery: **WebP** or optimized **PNG**
2. **Naming Convention**:
   - Use lowercase kebab-case (e.g., `hero-gradient-orb.webp`, `social-card-v1.png`).
3. **Optimization**:
   - Keep file sizes under 500KB where possible.
   - Use tools like TinyPNG or `imagemin` prior to committing.
4. **Dimensions**:
   - OpenGraph / Social preview cards: `1200 × 630` px
   - Hero background graphics: `1920 × 1080` px or vector SVG
