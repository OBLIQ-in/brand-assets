## 📸 Guidelines for Capturing Screenshots

1. **Resolution**: Minimum width 1920px (or 2x retina captures).
2. **Theme**: Consistent theme (dark surface or clean contrast surface as designed).
3. **Data**: Use realistic but non-confidential sample firm data (e.g. *Apex Advisory*, *Verma & Associates*).
4. **Format**: Crisp PNG or optimized WebP.
5. **Compression**: Run through `pngquant` or TinyPNG before committing to keep repository clone sizes light.
